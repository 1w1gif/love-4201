# 4201爱情故事

一个养成类网页游戏：捏主角、挑宠物、回合制对战、收集金币升级买衣服、2D 地图探索与第一章剧情；
另有「训练家广场」——注册训练家身份后，所有玩家互相可见、可切磋对决、可绑定亲密关系（羁绊）。

## 技术栈

- Next.js (App Router) + TypeScript —— `apps/web`
- `packages/art-engine` —— 程序化 SVG 形象生成（主角部件组合 / Q 版宠物）
- `packages/game-core` —— 战斗系统、经济、宠物养成数值、地图与剧情数据
- `apps/web/src/app/api/plaza` + `src/lib/plaza-db.ts` —— 广场服务端（JSON 文件数据库 `data/plaza-db.json`，
  含 8 位种子模拟玩家；注册玩家的档案、战绩、结缘关系都持久化在这里）

## 广场玩法

- 训练家列表：所有注册玩家（含模拟玩家）的头像、宠物、战绩互相可见
- 切磋：与任意玩家异步对战（对方宠物由系统代打），胜负战绩双方联网记录，胜者 +60 金币
- 结缘：向其他玩家申请绑定亲密关系，对方同意后成为羁绊；切磋胜利 +3 / 落败 +1 亲密度，每日问候 +2
- 亲密度 30 升「挚友」、80 升「灵魂羁绊」

## 运行

**日常游玩**（推荐）：双击项目根目录的

- `启动游戏.bat` —— 开发模式，秒开
- `启动游戏-正式版.bat` —— 生产模式，加载更快更流畅（首次需编译半分钟）

两者都会自动打开浏览器，关掉黑窗口即停止服务器。

**开发调试**：

```bash
npm install
npm run dev
```

打开 http://localhost:3000 。单机存档保存在浏览器 localStorage，广场数据保存在服务端 `data/`。

> 注意：`npm run build` 会与运行中的 dev 服务器共用 `.next` 缓存，构建前请先关掉 dev 服务器，否则可能损坏缓存导致页面 500。
